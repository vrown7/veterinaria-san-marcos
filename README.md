# Veterinaria San Marcos — Módulo: Tienda pública (navegación y catálogo)

Parte del proyecto EP1 de DSY1104 a cargo de **Nicolás Ortega**.
Cubre: `index.html`, `productos.html`, `detalle-producto.html`, `nosotros.html`, .

## Cómo abrir el sitio
No hay backend ni instalación. Basta con abrir `index.html` en el navegador.

## Estructura
```
├── index.html
├── productos.html
├── detalle-producto.html
├── nosotros.html
├── css/estilos.css       (una sola hoja de estilos, enlazada en las 4 páginas)
├── js/servicios.js       (datos de servicios + render de catálogo/detalle + carrito)
└── img/
```
